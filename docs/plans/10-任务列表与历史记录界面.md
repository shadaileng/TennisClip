## 一、背景与目标

### 现状问题

当前前端只展示**当前正在处理的任务**（`store.current`），任务完成并清除后，历史记录无法再查看。用户无法回顾过去的分析报告、重新下载集锦视频，缺乏基本的任务审计能力。

### 目标

1. 新增「历史任务」入口，展示所有历史处理记录列表
2. 支持点击某条记录查看完整详情（视频回放 + 分析报告）
3. 支持从历史记录中下载集锦视频和分析报告
4. 复用现有组件（StatusBadge / VideoPlayer / ReportView），保持 UI 一致性

### 不在范围内

- 后端无需修改：`GET /api/v1/db/tasks` 已存在，返回 `task_id / status / level / source_video / error / elapsed_seconds / created_at`
- 数据库无需迁移
- 不涉及任务删除/批量操作

## 二、方案设计

### 整体架构

```
用户点击「历史任务」按钮
  → store.showHistory = true
  → TaskHistory 组件 mount → store.loadTasks()
  → GET /api/v1/db/tasks → 渲染列表
  → 用户点击某行
  → store.viewTask(taskId) → GET /api/v1/tasks/{taskId}
  → store.showDetail = true → TaskDetailModal 渲染完整结果
```

### 数据来源

| 数据 | 接口 | 说明 |
|------|------|------|
| 任务列表 | `GET /api/v1/db/tasks?limit=50` | 数据库读取，按 created_at 倒序 |
| 单任务详情 | `GET /api/v1/tasks/{taskId}` | 内存队列读取完整 TaskResult（含 highlight / report） |
| 视频文件 | `GET /api/v1/tasks/{taskId}/video` | FileResponse 下载/播放 |
| 报告文件 | `GET /api/v1/tasks/{taskId}/report` | FileResponse 下载 |

### 组件设计

#### TaskHistory.vue

- **触发方式**：App.vue 头部「历史任务」按钮，控制 `store.showHistory`
- **布局**：右侧滑出面板（与 WorkflowPanel 类似的 slide-over 模式）
- **内容**：
  - 顶部：标题 + 刷新按钮 + 关闭按钮
  - 状态筛选：全部 / 完成 / 失败 / 处理中（标签切换）
  - 任务列表：每行显示状态徽章、视频文件名、分析层级、耗时、创建时间
  - 点击已完成任务行 → 调用 `store.viewTask(taskId)` 打开详情
  - 空状态提示
- **复用**：StatusBadge 组件展示状态

#### TaskDetailModal.vue

- **触发方式**：`store.showDetail = true` 时显示
- **布局**：全屏遮罩居中弹窗
- **内容**：
  - 顶部：任务状态 + 视频文件名 + 耗时 + 创建时间
  - 视频播放器（复用 VideoPlayer 组件）
  - 分析报告（复用 ReportView 组件）
  - 底部：下载集锦按钮 + 下载报告按钮 + 关闭按钮
- **数据**：从 `store.selectedTask` 读取完整 TaskResult

### Store 扩展（task.js）

```js
// 新增 state
tasks: [],              // 历史任务列表（来自 /api/v1/db/tasks）
loadingTasks: false,    // 列表加载中
showHistory: false,     // 历史面板开关
selectedTask: null,     // 选中查看详情的任务（完整 TaskResult）
showDetail: false,      // 详情弹窗开关

// 新增 actions
async loadTasks()       // GET /api/v1/db/tasks → this.tasks
async viewTask(id)      // GET /api/v1/tasks/{id} → this.selectedTask, this.showDetail = true
```

## 四、验收标准

1. 点击头部「历史任务」按钮，右侧滑出面板显示历史任务列表
2. 列表按创建时间倒序排列，显示状态徽章、文件名、层级、耗时、时间
3. 可按状态筛选（全部/完成/失败/处理中）
4. 点击已完成任务行，弹出详情弹窗
5. 详情弹窗内可播放集锦视频、查看分析报告
6. 可从详情弹窗下载集锦视频和分析报告文件
7. 刷新按钮可重新拉取最新列表
8. 空列表时显示友好提示
9. 现有上传/处理流程不受影响

## 五、风险与应对

| 风险 | 影响 | 应对方案 |
|------|------|---------|
| 任务从内存队列过期后详情无法读取 | 点击历史记录时 `GET /api/v1/tasks/{taskId}` 返回 404 | 详情弹窗提示「任务结果已过期」；列表仍可展示基本信息（来自数据库） |
| 历史列表过长导致性能问题 | 默认 limit=50，一般场景足够 | 后续可加分页，当前不做 |
| 视频文件被清理后无法播放 | FileResponse 返回 404 | VideoPlayer 组件已有兜底文案「集锦视频尚未生成」 |
