# 模型提供商多模型管理

## 背景与目标

原 `model_providers` 表每个提供商仅能配一个模型（`model` 单字符串），且密钥只存环境变量名（`api_key_env`）。本次改造让：

- 一个提供商可配置**多个模型**（`models` JSON 列表，首项为 `default_model`）；
- 密钥**直接入库明文**（`api_key`），接口返回**掩码**，管理页用密码框填写；
- 前端在上传面板提供「**提供商 + 具体模型**」双下拉，并新增「**模型管理**」弹窗支持在线增删改；
- 提交视频时由数据库 `is_active` + `selected_model` 唯一决定本次所用模型，无需改动 `/process` 契约。

参考 [TennisDiary](../../docs/reference/TennisDiary) 的 `ai_provider` 设计（name/base_url/api_key/models/default_model/enabled/sort_order）。

## 方案设计

### 数据模型（`backend/app/db_models.py`）

新增 `JSONList`（`Text` 存 JSON 数组，Python 侧透明为 `list[str]`，空/非 list 容错返回 `[]`）。`ModelProvider` 演进为：

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | String(64) | 唯一键，直选标识 |
| `base_url` | String(512) | OpenAI 兼容端点 |
| `api_key` | Text | 直接存密钥明文 |
| `models` | JSONList | 模型列表 |
| `selected_model` | String(128) | 当前所选模型 |
| `is_active` | Boolean | 是否生效 |
| `enabled` | Boolean | 是否可选（默认 True） |
| `sort_order` | Integer | 列表排序（默认 0） |

移除旧 `api_key_env`、`model`。`default_model`/`effective_model` 属性分别取 `models[0]` 与 `selected_model or models[0]`。

### 迁移（`backend/alembic/versions/c0a1b2d3e4f5_multi_model_provider.py`）

`op.batch_alter_table` 兼容 SQLite：新增列 → 数据迁移（旧 `model` → `models=[model]`、`selected_model=model`、`api_key=''`）→ 删除旧列。已验证旧库升级后表结构正确、数据迁移无误。

### 服务层（`backend/app/services/db_service.py`）

- `list_providers()` 按 `sort_order/name` 返回（api_key 已掩码）；
- `create_provider / update_provider / delete_provider`（重复名 409、删除激活项 409、base_url 须 http(s)、models 至少 1 项；更新时 api_key 留空保留原值）；
- `activate_provider(name, model=None)` 设 `is_active` 并写 `selected_model`（缺省取默认）；
- `select_model(name, model)` 仅更新所选模型；
- `mask_secret()` 掩码工具、`ProviderNotFound`/`ProviderConflict` 异常。

### 接口层（`backend/app/main.py`）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/v1/db/providers` | 列表（掩码） |
| POST | `/api/v1/db/providers` | 新增 |
| PUT | `/api/v1/db/providers/{name}` | 编辑 |
| DELETE | `/api/v1/db/providers/{name}` | 删除（激活项 409） |
| POST | `/api/v1/db/providers/{name}/activate?model=` | 切换生效（可选 model） |
| POST | `/api/v1/db/providers/{name}/select-model?model=` | 选模型 |

`/health` 的 `provider.model` 改为 `selected_model or default_model`，`api_key_set` 读 `api_key` 字段。`llm.py`/`environment.py` 同步改用 `api_key` 与 `effective_model`。

### 前端

- `api.js`：新增 `createProvider/updateProvider/deleteProvider/selectModel`，`activateProvider(name, model?)` 支持 model；
- `stores/task.js`：新增 `selectedModel` 与管理态（`managing/manageError/manageSaving`）及 `selectModel/createProvider/updateProvider/deleteProvider/openManage/closeManage`；
- `UploadPanel.vue`：升级为「提供商 + 模型」双下拉；
- `ProviderManageModal.vue`：新增管理弹窗（列表 + 增删改表单，密钥密码框、模型多行输入）；
- `App.vue`：顶栏新增「模型管理」按钮，挂载弹窗。
